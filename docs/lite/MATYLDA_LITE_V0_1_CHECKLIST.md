# Matylda Lite v0.1 Completion Checklist

## Purpose

Define what counts as a complete and usable Matylda Lite v0.1.

## v0.1 Is Complete When

- [x] `README_LITE.md` exists and explains the system.
- [x] `docs/lite/MATYLDA_LITE_SCOPE.md` exists.
- [x] `docs/lite/MATYLDA_LITE_USAGE_PROTOCOL.md` exists.
- [x] `docs/lite/MATYLDA_LITE_MEMORY_POLICY.md` exists.
- [x] `inbox/raw_notes.md` exists.
- [x] `library/THREAD_INDEX.md` exists.
- [x] At least 5 thread cards exist in `library/threads/`.
- [x] `desk/ACTIVE_THREADS.md` has no more than 5 active threads.
- [x] `desk/PARKING_LOT.md` contains valuable-but-not-now threads.
- [x] `desk/DECISION_LOG.md` records core Lite decisions.
- [x] `prompts/NEXT_PROMPTS.md` contains ready-to-use external prompts.
- [x] At least one real artifact exists under `artifacts/`.
- [x] At least one artifact has gone through hostile review or narrowing.
- [x] Weekly review procedure is documented.
- [x] Memory promotion is manual-only.
- [x] Non-autonomy rules are explicit.

## v0.1 Non-Goals

- no backend
- no API integrations
- no local LLM runtime
- no autonomous agent loop
- no automatic memory promotion
- no legal automation
- no self-expansion
